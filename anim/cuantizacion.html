Cuantización — cada bit de menos cuesta error

20 000 pesos simulados (σ = 1). Cada peso se redondea al nivel más cercano; con b bits hay 2b niveles. Abajo, el punto de este cuantizador frente al límite de tasa–distorsión.

Gris: histograma de los pesos. Líneas amarillas: los niveles permitidos (cada peso se redondea al más cercano). Zona roja: pesos fuera del rango, que se recortan al nivel extremo.
Curva blanca: límite de Shannon para pesos gaussianos, D/σ² = 2−2R. Puntos rojos: guardar cada peso con b bits fijos. Puntos teal: comprimir además los niveles con un código entrópico (≈ H(Ŵ) bits). El punto grande es el valor actual de b.
