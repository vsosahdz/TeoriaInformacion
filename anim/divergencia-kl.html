Divergencia KL — ¿cuántos bits de más cuesta usar el modelo equivocado?

La fuente real produce los símbolos a, b, c, d con probabilidades p. El código se diseñó pensando que eran q. Mueve las barras y observa el costo.
Arriba de cada slider: el peso del símbolo; las probabilidades se normalizan para que sumen 1. Azul = p (la fuente real) · amarillo = q (el modelo con el que se diseñó el código).

Término por término: p(x) · log₂ (p(x) / q(x))

Algunos términos salen negativos, pero la suma nunca es negativa.
